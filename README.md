# PS2 Emulator for PS3

Experimental PlayStation 2 software emulator bring-up for PlayStation 3, using PS3DEV and PSL1GHT.

Current development target: **Build 035**. This is an experimental PS2 CPU/BIOS bring-up, not a complete emulator.

The GitHub Actions workflow downloads the verified PS3DEV toolchain release from `khant735/PS3-PSU-Manager` and builds source files from this repository.
